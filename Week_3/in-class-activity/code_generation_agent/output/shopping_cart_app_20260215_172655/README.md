# Shopping Cart App

A Streamlit-based shopping cart application.

## Features
- Product listing
- Add/remove items from cart
- Checkout functionality
- Persistent cart state

## Installation
```bash
pip install -r requirements.txt
```

## Running the App
```bash
streamlit run src/main.py
```

## Testing
```bash
pytest tests/
```

## Usage Example
1. Run the app using `streamlit run src/main.py`
2. Browse the product list
3. Click "Add to Cart" to add items
4. View your cart and adjust quantities
5. Proceed to checkout
